# Glossário — FitManager

Este documento apresenta os principais termos utilizados no sistema FitManager, com o objetivo de padronizar a comunicação entre os integrantes da equipe e facilitar o entendimento do projeto.

## 1. Perfis de usuário

| Termo | Definição |
|---|---|
| Administrador | Usuário responsável pela administração geral do sistema, gerenciamento de planos, instrutores e relatórios. |
| Atendente | Usuário responsável pelo cadastro e consulta de alunos, matrículas, pagamentos e registros de entrada. |
| Instrutor | Profissional responsável pela elaboração de treinos e registro de avaliações físicas. |
| Aluno | Pessoa matriculada na academia que pode consultar a validade do plano e seus treinos. |

## 2. Termos relacionados à academia

| Termo | Definição |
|---|---|
| Aluno | Pessoa cadastrada no sistema para utilizar os serviços da academia. |
| Matrícula | Registro que estabelece o vínculo do aluno com a academia. |
| Plano | Modalidade de contratação que define as condições e o período de acesso aos serviços da academia. |
| Mensalidade | Valor cobrado periodicamente pela utilização dos serviços da academia. |
| Renovação | Processo de extensão do período de uma matrícula. |
| Cancelamento | Encerramento do vínculo de uma matrícula. |
| Pagamento | Registro de uma quitação financeira realizada pelo aluno. |
| Inadimplência | Situação em que um pagamento não foi realizado dentro do prazo estabelecido. |
| Frequência | Registro das entradas do aluno na academia. |
| Treino | Conjunto de exercícios elaborado pelo instrutor para o aluno. |
| Avaliação física | Registro de informações físicas do aluno para acompanhamento de sua evolução. |

## 3. Termos relacionados ao sistema

| Termo | Definição |
|---|---|
| Autenticação | Processo de identificação do usuário por meio de suas credenciais de acesso. |
| Autorização | Controle das funcionalidades que cada perfil pode acessar. |
| Interface gráfica | Parte visual do sistema com a qual o usuário interage. |
| Banco de dados | Local onde as informações do sistema são armazenadas. |
| CRUD | Conjunto de operações de criação, consulta, atualização e exclusão de registros. |
| Persistência | Capacidade de armazenar informações para que permaneçam disponíveis após o encerramento do sistema. |

## 4. Tecnologias utilizadas

| Termo | Definição |
|---|---|
| Java | Linguagem de programação utilizada no desenvolvimento do sistema. |
| JavaFX | Tecnologia utilizada para desenvolver a interface gráfica. |
| FXML | Linguagem baseada em XML utilizada para estruturar as telas JavaFX. |
| CSS | Linguagem utilizada para estilizar a interface gráfica. |
| Maven | Ferramenta utilizada para gerenciar dependências e a construção do projeto. |
| SQLite | Sistema de gerenciamento de banco de dados utilizado no projeto. |
| JDBC | Tecnologia que permite a comunicação entre a aplicação Java e o banco de dados. |

---

**Observação:** Este glossário poderá ser atualizado conforme novas funcionalidades e termos forem incorporados ao FitManager.
